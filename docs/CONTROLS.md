# ปุ่มควบคุม

ออกแบบจาก **จอยเกม** ก่อน แล้วจึงแมปลงทัชสกรีนและคีย์บอร์ด
(ผังจอยอ้างอิงมาตรฐาน Standard Gamepad ของเบราว์เซอร์ — Xbox/PlayStation/จอยจีนใช้ได้หมด)

| การกระทำ | จอยเกม | คีย์บอร์ด | มือถือ |
|---|---|---|---|
| เดิน | อนาล็อกซ้าย | `WASD` / ลูกศร | จอยหลอกซ้าย |
| เล็งสกิลลงพื้น | อนาล็อกขวา | ใช้เป้าหมายปัจจุบัน | ใช้เป้าหมายปัจจุบัน |
| โจมตี (ค้างไว้ได้) | `X` หรือ `RT` | `Space` | ปุ่ม ⚔ |
| คุย NPC / เก็บของ | `A` | `E` | ปุ่ม ✋ |
| เก็บของอย่างเดียว | `Y` | `Z` | — |
| ยกเลิก / ปิดหน้าต่าง | `B` | `Esc` | ปุ่ม ✕ |
| เป้าหมายถัดไป / ก่อนหน้า | `RB` / `LB` | `Tab` / `Q` | ปุ่ม 🎯 |
| สกิล 1–4 | ปุ่มทิศ (D-pad) | `1`–`4` | ปุ่ม 1–4 |

| แชท | — | `Enter` | แตะช่องแชท |
| วิธีเล่น | — | `F1` | ปุ่ม ❓ |

## เล่นบนมือถือ

เกมออกแบบมาสำหรับ **แนวนอน** — จอกว้างทำให้เห็นสนามรบมากพอ และวางจอยหลอกไว้
ใต้นิ้วโป้งซ้าย ปุ่มโจมตีใต้นิ้วโป้งขวาได้โดยไม่ทับกัน

ถ้าถือเครื่องแนวตั้ง เกมจะขึ้นหน้าจอให้หมุนเครื่อง พร้อมปุ่ม
**"เต็มจอ + ล็อกแนวนอน"** ถ้าเบราว์เซอร์หมุนให้ไม่ได้ (iOS ไม่มี API ล็อกการหมุน
และหน้าที่ฝังใน iframe มักถูกบล็อก) จะมีปุ่ม **"ให้เกมหมุนภาพเอง"** ขึ้นมาแทน —
เกมจะหมุนทั้งหน้า 90° ด้วยตัวเอง ผู้เล่นแค่ถือเครื่องตะแคงก็เล่นได้เหมือนกัน
(ทิศของจอยหลอกถูกหมุนกลับให้ตรงกับภาพแล้ว) หรือกด "เล่นแนวตั้งต่อไป" เพื่อข้าม

เลย์เอาต์แนวนอนบนมือถือ: สถานะ+EXP มุมซ้ายบน · เงินกลางบน · แผนที่มุมขวาบน ·
เมนูไอคอนสองแถวขวา · แถบ AUTO/เป้าหมาย/ของใช้ด่วนเหนือปุ่มโจมตี ·
จอยหลอกซ้ายล่าง · ปุ่มขวาล่าง · แชทกลางซ้ายเหนือจอย

## หมายเหตุการออกแบบ

* **ไม่มีอะไรที่ต้องใช้เมาส์** ทุกอย่างเล่นจบด้วยจอยได้ รวมถึงเมนูทุกหน้า
* สกิลที่ต้องเลือกจุดบนพื้น (เช่น รูนพายุ, ห่าธนู) ใช้อนาล็อกขวาชี้ทิศ
  ถ้าไม่ได้ขยับอนาล็อกขวา จะยิงไปที่เป้าหมายปัจจุบัน หรือหน้าตัวละคร
* การโจมตีเป็นแบบ "ค้างปุ่ม" ไม่ใช่กดรัว — ความเร็วโจมตีคุมด้วย AGI/DEX ตามสูตร
* ไคลเอนต์ทำนายการเดินเองและแก้ตามเซิร์ฟเวอร์ทีหลัง จึงยังลื่นแม้ปิงสูง

## ระยะกล้อง

กล้องมีสี่สเต็ป — **ไกลมาก / ไกล / กลาง / ใกล้** — สลับได้ด้วย `-` `=` บนคีย์บอร์ด
กดอนาล็อกขวา (R3) บนจอย หรือเลือกในหน้าตั้งค่า ค่าเริ่มต้นคือ **กลาง**
และระบบจำค่าที่เลือกไว้ในเบราว์เซอร์นี้ ระยะจริงยังปรับตามความกว้างจอด้วย
เพื่อให้จอมือถือไม่แคบเกินไป

## เสียง

เสียงทุกอย่างสังเคราะห์สดด้วย WebAudio ในเบราว์เซอร์ — เกมไม่มีไฟล์เสียงเลย
เพลงบรรยากาศจึงไม่ต้องดาวน์โหลดและเปลี่ยนตามธีมของโซน (เมือง / ทุ่ง / บึง /
สุสาน / ภูเขาหิน / น้ำแข็ง) เสียงเอฟเฟกต์มีการแพนซ้าย-ขวาและเบาลงตามระยะห่าง
จากตัวเรา ปรับระดับเสียงรวม / เอฟเฟกต์ / เพลง ได้ในหน้าตั้งค่า และกด `M`
เพื่อปิดเสียงทั้งหมด ระบบจำค่าไว้ในเบราว์เซอร์นี้

เบราว์เซอร์ทุกตัวห้ามเล่นเสียงก่อนผู้ใช้แตะหน้าจอ เสียงจึงเริ่มทำงานหลังการ
กดครั้งแรก (ล็อกอินก็นับ)
