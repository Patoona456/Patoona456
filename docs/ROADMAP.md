## รอบถัดไป (ลำดับความสำคัญ)
0. **เสียง** และ **แอนิเมชันโจมตีที่ชัดขึ้น** (ยังรู้สึกเงียบเวลาตี)
1. **เทรดตัวต่อตัว** — มีช่อง opcode ไว้แล้ว (`OP.TRADE`) ต้องทำ UI ยืนยันสองฝั่ง
2. **แผงขายของแบบนั่งขาย (vendor stall)** — ให้ผู้เล่นตั้งร้านในเมืองได้
3. **กิลด์** + คลังกิลด์ + สงครามชิงป้อม (ใช้โครง party เดิมขยายได้)
4. **PvP** ในโซนที่กำหนด พร้อมสูตรลดดาเมจระหว่างผู้เล่นแยกจาก PvE
5. **ย้ายฐานข้อมูลเป็น SQLite/Postgres** — `server/persistence.js` ถูกแยกไว้ให้สลับได้ทันที
6. **ระบบการ์ด/รูนฝังของ** — โครงสร้าง `cards.size / cards.race` มีในสูตรดาเมจแล้ว
7. **เสียงและดนตรี** (ยังไม่มีไฟล์เสียงที่สัญญาอนุญาตเข้ากันในโปรเจกต์)
8. **แพ็กเกจมือถือ** ด้วย Capacitor — ไคลเอนต์เป็นเว็บล้วนอยู่แล้ว ทำได้เลย
9. **เมทริกซ์สมดุล** — ดึง `world.stats.minted/burned` ออกเป็นหน้าแดชบอร์ดผู้ดูแล

## หนี้ทางเทคนิคที่รู้ตัว
- สถานะเก็บใน JSON ไฟล์เดียว: พอสำหรับผู้เล่นหลักร้อย ไม่พอสำหรับหลักหมื่น
- ปาร์ตี้อยู่ในหน่วยความจำ หายเมื่อรีสตาร์ตเซิร์ฟเวอร์ (ตั้งใจในเฟสนี้)
- ยังไม่มีการเข้ารหัสข้อความ/การจำกัดจำนวนบัญชีต่อ IP
- AI มอนสเตอร์เป็น state machine ง่ายๆ ยังไม่มีการหาเส้นทางอ้อมสิ่งกีดขวาง
