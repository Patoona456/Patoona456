- [x] **เควสต์ 39 อัน** ครบทุกแถบเลเวลถึง 70 พร้อมระบบเดินออโต้ไปทำและกลับมาส่งเอง
- [x] **เปลี่ยนอาชีพที่เลเวล 10** พร้อมบททดสอบและชุดเริ่มต้น (16 อาชีพ 3 ชั้น)
- [x] ปาร์ตี้ 6 คน แชท 5 ช่อง **เทรดตัวต่อตัว** (ยืนยันสองฝั่ง ล็อกก่อนตกลง)
- [x] **กิลด์เก็บลงฐานข้อมูลจริง**: ยศ 5 ขั้น คลังกิลด์ล็อกสิทธิ์ตามยศ
      ค่าก่อตั้ง+ค่าบำรุงรายสัปดาห์ แชทกิลด์ และปาร์ตี้ย้ายลง DB ด้วย
      (ทดสอบแล้วว่ารอดจากการรีสตาร์ตเซิร์ฟเวอร์)
- [x] **แดชบอร์ดเศรษฐกิจ** ที่ `/admin` แยกได้ว่าท่อระบายไหนทำงานจริง
- [x] **จำกัดบัญชีต่อ IP** (`EMBERFALL_MAX_ACCOUNTS_PER_IP`)
- [x] **ดันเจียนปาร์ตี้ + บอสที่มีกลไกจริง + ล็อกรางวัลรายสัปดาห์**

### ปลายเกมและการปะทะกัน
- [x] **บอสมีสคริปต์ครบทั้งสามตัว** — กรูมไล่ชาร์จคนที่ยืนไกลสุดและเรียกหมู่รบที่
      "ทำให้เขาคมขึ้น" ไม่ใช่ฮีลให้ · วาลฆ่าคนที่ขอบวงและไว้ชีวิตคนกลางวง
      (ตรงข้ามกับผู้พิทักษ์หีบศพ) แล้วผูกสองคนด้วยสายเย็นที่เจ็บเมื่ออยู่ห่างกัน
- [x] **PvP** เฉพาะในลานประลองเถ้า ประตูเดียว เดินเข้าเองเท่านั้น
      มีสูตรลดดาเมจของตัวเอง (42% และเพดานต่อครั้ง 28% ของหลอด) แพ้แล้วไม่เสีย EXP
      และผู้ชนะไม่ได้อะไร — ป้องกันการฟาร์มกันเองสองบัญชี
- [x] **สงครามชิงป้อม** — ศึกเปิดวันอาทิตย์ 20:00 UTC หนึ่งชั่วโมงเท่ากันทุกโซนเวลา
      ยืนบนบัลลังก์ 90 วินาทีโดยไม่มีกิลด์อื่นบนนั้น **รางวัลคือไม่ต้องจ่ายค่าบำรุง
      สัปดาห์นั้น ไม่ใช่เงิน** เพราะจ่ายเงินให้กิลด์ที่แข็งที่สุดทุกสัปดาห์คือทางที่
      เศรษฐกิจเหลือกิลด์เดียว

### การค้าและของสะสม
- [x] **แผงขายของผู้เล่น** — ตั้งได้เฉพาะในเมือง ต้องยืนเฝ้าเอง ไม่มีค่าธรรมเนียมตั้ง
      หักภาษี 5% เมื่อขายได้ · **ของอยู่ในกระเป๋าผู้ขายจนกว่าจะมีคนจ่าย** จึงไม่มี
      escrow ให้กระทบยอด และไม่มีอะไรก๊อปปี้ได้ถ้ากระบวนการตายกลางคัน
- [x] **ระบบการ์ดฝังของ** — 10 ใบ ดรอปจากมอนที่เป็นชื่อการ์ดเอง (0.4% / บอส 5%)
      เติมค่าให้ `cards.size` กับ `cards.race` ที่เป็นรูว่างในสูตรดาเมจมาตลอด
      **ฝังแล้วถอดไม่ได้** ซึ่งคือจุดประสงค์ ไม่ใช่ข้อจำกัด — การ์ดที่ย้ายไปมาได้
      คือการ์ดที่ทุกคนมีใบเดียวแล้วหมุนใช้ ส่วนการ์ดที่ผูกติดทำให้ของชิ้นนั้น
      เป็นของที่ใครบางคนสร้างขึ้น
- [x] **สิทธิ์พิเศษของผู้ถือป้อม** — สมาชิกได้ EXP +5% ตลอดสัปดาห์ที่ถือป้อม
      เลือกให้เป็น EXP เพราะเป็นรางวัลเดียวที่ไม่ไปบิดเศรษฐกิจที่ตั้งใจให้เงินหายาก

      ตอนนี้ส่งเฉพาะตอนเปลี่ยน **แบนด์วิดท์ลง 2.9 เท่า (401.5 → 139.8 KB/วินาที/คน)**

      เขียนลงดิสก์อยู่ไหม (บั๊กที่เคยทำให้โลกไม่เซฟเงียบๆ อยู่หลายคอมมิต)

## รอบถัดไป (ลำดับความสำคัญ)

1. **แพ็กเกจมือถือ** ด้วย Capacitor — ไคลเอนต์เป็นเว็บล้วนอยู่แล้ว ทำได้เลย
2. **ลานประลองเถ้าเป็นสนามเปล่า** — ยังไม่มีสิ่งกีดขวางให้ใช้เชิงยุทธวิธี
3. **AI มอนสเตอร์ร่วมมือกัน** — ตอนนี้เดินอ้อมเป็นแล้ว แต่ยังต่างตัวต่างตี
4. **ถอดการ์ด** ถ้าจะมี ต้องแพงมากและทำลายของหรือการ์ดอย่างใดอย่างหนึ่ง
   ไม่งั้นจะล้มเหตุผลทั้งหมดที่ทำให้การ์ดมีค่า

## หนี้ทางเทคนิคที่รู้ตัว
- AI มอนสเตอร์ยังเป็น state machine ง่ายๆ (เดินอ้อมเป็นแล้ว แต่ยังไม่มีการร่วมมือกัน)
- ศิลป์ LPC มีเกราะสูงสุดแค่ชั้น golden และอาวุธมีแค่ 3 แบบ ของปลายเกมจึงใช้
  วิธีย้อมสีรายชั้น (`sprite.tint`) แทนการเพิ่มไฟล์ภาพ
- แผงขายของอยู่ในหน่วยความจำ ไม่ได้เขียนลงฐานข้อมูล — ตั้งใจให้เป็นแบบนั้น
  (แผงคือคนที่ยืนอยู่ตรงนั้น) แต่แปลว่ารีสตาร์ตเซิร์ฟเวอร์แล้วแผงหายหมด
