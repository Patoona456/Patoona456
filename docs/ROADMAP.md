# แผนพัฒนาต่อ

## ทำเสร็จแล้ว (เล่นได้จริง)

### แกนกลาง
- [x] เซิร์ฟเวอร์ authoritative 20 Hz + สแนปช็อต 10 Hz + AOI
- [x] บัญชี/ตัวละคร (scrypt) เก็บลง **SQLite (`node:sqlite`, WAL)** + สำรองข้อมูลร้อน
- [x] แผนที่ **10 โซน** — 7 โซนสร้างจาก seed + **ดันเจียน 3 ชั้นที่เขียนผังด้วยมือ**
- [x] ต่อสู้ครบ: ตีปกติ 56 สกิล ธาตุ สถานะผิดปกติ threat ลีช
- [x] มอนสเตอร์ **41 ชนิด** รวมบอส 3 ตัว + สัตว์เลี้ยงเรียกได้ (โซนละ 7-8 ชนิด)
- [x] **มอนสเตอร์เดินอ้อมสิ่งกีดขวางเป็น** (BFS ใช้ร่วมกับเดินออโต้ฝั่งไคลเอนต์)
- [x] ไอเทม **109 ชิ้น** + สูตรคราฟต์ 24 สูตร สวมใส่ ตีบวก ซ่อม น้ำหนัก ความคงทน
      **ทุกชิ้นมีทางได้มาจริง** (เคยมี 31 ชิ้นที่อยู่ในตารางเฉยๆ ไม่มีมอนดรอปและไม่มีสูตร)
- [x] เศรษฐกิจครบวง: ร้าน NPC ตัวหน่วงราคา ตลาดผู้เล่น คลังเก็บของ ค่าเดินทาง
- [x] **กาชา + กล่องสุ่ม + ร้านแลกเศษรุ่งอรุณ** (ของทุกชิ้นในกาชาซื้อตรงได้)
- [x] **เควสต์ 39 อัน** ครบทุกแถบเลเวลถึง 70 พร้อมระบบเดินออโต้ไปทำและกลับมาส่งเอง
- [x] **เปลี่ยนอาชีพที่เลเวล 10** พร้อมบททดสอบและชุดเริ่มต้น (16 อาชีพ 3 ชั้น)
- [x] ปาร์ตี้ 6 คน แชท 5 ช่อง **เทรดตัวต่อตัว** (ยืนยันสองฝั่ง ล็อกก่อนตกลง)
- [x] **กิลด์เก็บลงฐานข้อมูลจริง**: ยศ 5 ขั้น คลังกิลด์ล็อกสิทธิ์ตามยศ
      ค่าก่อตั้ง+ค่าบำรุงรายสัปดาห์ แชทกิลด์ และปาร์ตี้ย้ายลง DB ด้วย
      (ทดสอบแล้วว่ารอดจากการรีสตาร์ตเซิร์ฟเวอร์)
- [x] **แดชบอร์ดเศรษฐกิจ** ที่ `/admin` แยกได้ว่าท่อระบายไหนทำงานจริง
- [x] **จำกัดบัญชีต่อ IP** (`EMBERFALL_MAX_ACCOUNTS_PER_IP`)
- [x] **ดันเจียนปาร์ตี้ + บอสที่มีกลไกจริง + ล็อกรางวัลรายสัปดาห์**

## รอบถัดไป (ลำดับความสำคัญ)

1. **บอสอีกสองตัวยังไม่มีสคริปต์** — `server/game/boss.js` ตั้งมาตรฐานไว้เองว่า
   "การสุ่มสกิลไม่ใช่กลไก มันคือสภาพอากาศ" แต่มีผู้พิทักษ์หีบศพตัวเดียวที่มีสคริปต์จริง
   จอมทัพออร์คกับราชันโครงกระดูกเป็นบอสรายสัปดาห์ที่ควรเป็นจุดนัดพบของกิลด์
2. **สงครามชิงป้อมระหว่างกิลด์** — กิลด์มีแล้ว จ่ายค่าก่อตั้ง 250,000 และค่าบำรุง
   40,000/สัปดาห์ แต่ยังไม่มีอะไรให้แย่งกัน
3. **PvP** ในโซนที่กำหนด พร้อมสูตรลดดาเมจระหว่างผู้เล่นแยกจาก PvE (ยังไม่มีเลยสักบรรทัด)
4. **แผงขายของแบบนั่งขาย (vendor stall)** — ให้ผู้เล่นตั้งร้านในเมืองได้
5. **ระบบการ์ด/รูนฝังของ** — โครงสร้าง `cards.size / cards.race` มีในสูตรดาเมจแล้ว
6. **แพ็กเกจมือถือ** ด้วย Capacitor — ไคลเอนต์เป็นเว็บล้วนอยู่แล้ว ทำได้เลย

## หนี้ทางเทคนิคที่รู้ตัว
- กิลด์ยังไม่มีอะไรให้แย่งกัน (ไม่มีป้อม ไม่มีสงคราม) จึงยังผูกคนได้ไม่สุด
- AI มอนสเตอร์ยังเป็น state machine ง่ายๆ (เดินอ้อมเป็นแล้ว แต่ยังไม่มีการร่วมมือกัน)
- สายฮีล (สาธุคุณ) ฆ่าช้ากว่าสายเวท 3.1 เท่า และ ใบมีดราตรี ตามหลัง จอมกล อยู่
  ทุกสายยัง "ฆ่าได้ 4-11 ตัวก่อนเลือดหมด" คือเล่นได้จริง แต่ยังไม่เท่ากัน
- ศิลป์ LPC มีเกราะสูงสุดแค่ชั้น golden ชุดปลายเกมจึงใช้วิธีย้อมสีรายชั้น
  (`sprite.tint`) แทนการเพิ่มไฟล์ภาพ
