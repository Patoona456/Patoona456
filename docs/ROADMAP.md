## รอบถัดไป (ลำดับความสำคัญ)

1. **สงครามชิงป้อมระหว่างกิลด์** — กิลด์มีแล้ว แต่ยังไม่มีอะไรให้กิลด์แย่งกัน
   ซึ่งเป็นสิ่งที่ทำให้กิลด์มีความหมายจริงๆ ในระยะยาว
2. **แผงขายของแบบนั่งขาย (vendor stall)** — ให้ผู้เล่นตั้งร้านในเมืองได้
3. **PvP** ในโซนที่กำหนด พร้อมสูตรลดดาเมจระหว่างผู้เล่นแยกจาก PvE
4. **ระบบการ์ด/รูนฝังของ** — โครงสร้าง `cards.size / cards.race` มีในสูตรดาเมจแล้ว
5. **บอสที่เขียนสคริปต์เพิ่ม** — ตอนนี้มีตัวเดียว อีกสองตัวยังสุ่มสกิลแบบเดิม
6. **แพ็กเกจมือถือ** ด้วย Capacitor — ไคลเอนต์เป็นเว็บล้วนอยู่แล้ว ทำได้เลย

## หนี้ทางเทคนิคที่รู้ตัว
- กิลด์ยังไม่มีอะไรให้แย่งกัน (ไม่มีป้อม ไม่มีสงคราม) จึงยังผูกคนได้ไม่สุด
- AI มอนสเตอร์ยังเป็น state machine ง่ายๆ (เดินอ้อมเป็นแล้ว แต่ยังไม่มีการร่วมมือกัน)
