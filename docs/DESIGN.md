# Emberfall Online — เอกสารออกแบบเกม

## 1. โลกและโทนเรื่อง

หลัง "คืนเถ้าถ่าน" (The Emberfall) เศษดาวไฟตกลงกลางทวีป เผาอาณาจักรเก่าจนราบ
สิ่งที่เหลือคือเมืองชายแดน **เอมเบอร์โฮลด์** กับซากโลกที่ธาตุไฟยังไม่ดับ
ผู้เล่นคือ "ผู้เก็บซาก" (Reclaimer) ที่ออกไปเก็บของจากซากอารยธรรม

โทนเรื่อง: ชนบทกึ่งดาร์กแฟนตาซี ไม่ซีเรียสเกิน เน้นการสะสมและการค้าระหว่างผู้เล่น

## 2. อาชีพ (16 อาชีพ, 3 ชั้น)

```
ผู้แรกเริ่ม (Novice)
├─ ทหารหน้า Vanguard ──┬─ กำแพงเหล็ก Bulwark      (แท็งก์เต็มตัว)
│                      └─ ผู้บ้าคลั่ง Ravager      (แลกเลือดเอาดาเมจ)
├─ นักเดินเงา Wayfarer ┬─ ใบมีดราตรี Nightblade   (ล่องหน ลอบสังหาร)
│                      └─ จอมกล Trickster         (ดีบัฟ กับดัก ขโมย)
├─ พรานธนู Marksman ───┬─ มือแม่นธนู Sharpshooter (ยิงไกล ทะลุแนว)
│                      └─ ผู้เรียกสัตว์ Beastcaller(สู้คู่สัตว์เลี้ยง)
├─ นักร่ายรูน Runecaster┬─ จอมเวทย์รูน Arcanist    (เวทย์วงกว้าง)
│                      └─ ผู้ขับสายฟ้า Stormsinger(สายฟ้าต่อเนื่อง)
└─ ผู้พิทักษ์ Warden ──┬─ สาธุคุณ Hierophant      (ฮีล/ชุบ/บัฟ)
                       └─ ผู้ถือคำสาบาน Oathkeeper(ตีผสมแสง)
```

* **เปลี่ยนอาชีพชั้น 1 ที่เลเวล 10** (เลเวลตัวละคร ไม่ใช่ Job Level — ทุกคนไปถึงแน่นอน
  ไม่ต้องไปนั่งไล่ Job Level ก่อน) ส่วนชั้น 2 ที่ **เลเวล 45 + Job Lv.40**
* เปลี่ยนอาชีพแล้ว Job Level รีเซ็ตเป็น 1 แต่สกิลเดิมยังอยู่ (เรียนต่อยอดได้)
* **ได้ชุดเริ่มต้นของอาชีพทันทีและสวมให้อัตโนมัติ** — พรานธนูที่ไม่มีธนูคือพรานธนูที่
  โจมตีไม่ได้เลย เกมจึงไม่ปล่อยให้เดินออกจากครูฝึกไปมือเปล่า
* **บททดสอบประจำสาย** (ไม่บังคับ): ทำก่อนเปลี่ยนอาชีพจะได้ของชุดใหญ่ เงิน และ
  **แต้มสกิลเพิ่มอีก 1** — เป็นเนื้อหาให้คนที่อยากอินกับการเลือกทาง ไม่ใช่กำแพงสำหรับคนรีบ

| สาย | บททดสอบ (ทำได้ที่เลเวล 10) |
|---|---|
| ทหารหน้า | ล่าซากเถ้า 12 ตัว + เศษกระดูก 8 ชิ้น (ทนให้ไหวก่อน) |
| นักเดินเงา | ไล่ดับดวงไฟเร่ร่อน 15 ดวง (ไล่ให้ทันก่อน) |
| พรานธนู | ล่าสไลม์โคลน 20 ตัว + หนังหนู 8 ผืนทำสายธนู |
| นักร่ายรูน | ถ่านอังคาร 2 + มัดสมุนไพร 15 ทำหมึกรูน |
| ผู้พิทักษ์ | มัดสมุนไพร 20 + เศษกระดูก 10 ทำยาและเครื่องราง |
* อาวุธจำกัดตามอาชีพจริง **12 ชนิด** (`shared/weapons.js`):
  `sword greatsword dagger axe spear bow staff wand knuckle throwing shield special`
  ชนิดหนึ่งบอกทั้งจำนวนมือ ท่าฟัน และเป็นอาวุธเวทหรือไม่ — เซิร์ฟเวอร์ ไคลเอนต์
  และตารางไอเทมอ่านจากตารางเดียวกัน แทนที่จะเดาจากชื่อคนละที่
* สองมือคือการแลกจริง: `staff` เวทแรงกว่า `wand` แต่เสียช่อง offhand ไป
  เช่นเดียวกับ `bow` กับ `throwing` — ธนูไกลกว่า แต่ของขว้างยังถือโล่ได้
* `special` เป็นของไม่กี่ชิ้นที่ไม่มีคลาส ไม่มีบันได และทุกอาชีพถือได้

## 3. สเตตัสและสูตร

หกสเตตัสแบบคลาสสิก **STR / AGI / VIT / INT / DEX / LUK**
ราคาแต้มเพิ่มขึ้นตามค่า (`floor((ค่าปัจจุบัน-1)/10)+2`) เหมือนเกมยุคเดียวกัน

| ค่า | สูตรย่อ |
|---|---|
| MaxHP | `(45 + Lv·16 + VIT·6 + Lv·VIT·0.3 + JobLv·3) × ตัวคูณอาชีพ` |
| MaxSP | `(24 + Lv·2.4 + INT·4 + Lv·INT·0.07 + JobLv·1.2) × ตัวคูณอาชีพ` |
| SP ฟื้น | `MaxSP/18 + INT/4` ต่อ 4 วินาที (นอกคอมแบตคูณสอง) |
| ATK | `STR + STR²/40 + DEX/4 + LUK/5 + Lv/4` |
| MATK | `INT + INT²/32 + DEX/6 + LUK/6 + Lv/4` |
| HIT / FLEE | `80 + DEX + Lv/2` / `60 + AGI + Lv/2.4` |
| CRIT | `1 + LUK·0.32` % (ลดด้วย LUK ของเป้าหมาย) |
| ความเร็วโจมตี | `ดีเลย์อาวุธ × (1 − AGI·0.0042 − DEX·0.0011)` ต่ำสุด 0.32 เท่า |
| ลดเวลาร่าย | `1 − DEX·0.0035 − INT·0.0015` ต่ำสุด 0.2 เท่า |

| MDEF | `Lv·2.2 + VIT·1.2 + INT·2` + ของสวมใส่ |

**ดาเมจ**: `พลัง × อัตราสกิล × สุ่ม0.9–1.1 × ตัวคูณธาตุ × (1−ลดจาก DEF แข็ง) − DEF อ่อน`
DEF แข็งเป็นการลดแบบ diminishing (`def/(def+120+4·Lv)`) จึงไม่มีทางอมตะ
คริติคอลคูณ 1.5 และข้ามครึ่งหนึ่งของ DEF

MDEF มีพื้นฐานตามเลเวลด้วย ไม่ได้มาจากของสวมใส่กับ INT อย่างเดียว ทั้งเกมมีของ
ที่ให้ MDEF อยู่ 7 ชิ้น สายที่ไม่ลง INT จึงเคยรับเวทเต็มๆ จนมอนสายเวทฆ่าตัวเลเวล 70
ได้ในสองครั้ง พื้นฐานนี้ทำให้เวทโดนลดราว 1/3 เท่ากับที่เกราะธรรมดาลดอาวุธ
ส่วนสาย INT กับของ MDEF ก็ยังได้มากกว่านั้นตามเดิม

**EXP ตามช่องว่างเลเวล** (`expGapPenalty`): มอนที่เลเวลเท่ากันหรือสูงกว่าให้เต็ม
ต่ำกว่าเกิน 4 เลเวลเริ่มลดแบบ `0.86^n` และสูงกว่าเกิน 14 เลเวลค่อยๆ ลดลงถึง 25%
ทั้งสองฝั่งไม่มีหน้าผา — หน้าผาคือสาเหตุที่มอนถูกๆ ตัวเดียวเคยคุ้มที่สุดยาว 25 เลเวล

**SP คือสิ่งที่ทำให้รอบสกิลเป็นรอบสกิลจริงๆ** ตอนที่มันฟื้นแค่ 1/90 ของหลอดต่อตี
ตัวเลเวล 70 ได้กลับมา 0.75 หน่วยต่อวินาที ขณะที่สกิลหนึ่งครั้งกิน 20-70 หน่วย
ผลคือทุกอาชีพในเกมเปิดหัวด้วยสกิลแล้วตีธรรมดาไปจนจบ — ซึ่งบังเอิญตรงกับที่
เครื่องมือวัดสมดุลเคยคิดว่าเกมนี้เป็น ตอนที่มันยังไม่รู้จักสกิล

**PvP ใช้สูตรของตัวเอง** (`pvpDamage`): ดาเมจเหลือ 42% และมีเพดานต่อครั้งที่ 28%
ของหลอดเลือดเป้าหมาย ตัวเลข PvE ที่จูนให้ฆ่ามอนใน 15 วินาที เอามาชนกันเองจะจบใน
2-3 วินาที ซึ่งไม่ใช่การต่อสู้ แต่เป็นการวัดว่าใครกดก่อน เพดานต่อครั้งสำคัญกว่าตัวคูณ:
ถ้าไม่มี สกิลเปิดตัวเดียวก็จบก่อนภาพเตือนจะวาดเสร็จ

**ตารางธาตุ 8 ธาตุ** (neutral / fire / ice / lightning / earth / wind / holy / dark)
เป็นวงจรแพ้ชนะของเราเอง โครงเป็นวงห้าธาตุที่ปิดครบ — fire > wind > earth >
lightning > ice > fire (×1.5 ตามทาง ×0.75 ย้อนทาง) แยก holy ↔ dark ออกมาเป็นคู่
ที่แรงใส่กันมาก (×1.75–1.9) และไม่แพ้ชนะกับใครอีกเลย ธาตุใส่ตัวเองได้แค่ ×0.5
ทำให้ของธาตุมีตลาดจริงต่อแต่ละดันเจี้ยน

ชื่อธาตุชุดเก่า (ember frost storm verdant shade radiant) ยังอ่านได้จากเซฟเก่า
ผ่าน `ELEMENT_ALIASES` ใน `shared/elements.js` — แปลงเป็นชื่อใหม่ตอนคำนวณ
ทั้งสีและดาเมจ จึงไม่มีของชิ้นไหนกลายเป็นไร้ธาตุเพราะการเปลี่ยนชื่อ

## 4. การต่อสู้

* เซิร์ฟเวอร์ตัดสินทุกอย่างที่ 20 ครั้ง/วินาที ส่งสแนปช็อต 10 ครั้ง/วินาที
* โจมตีอัตโนมัติแบบ "ค้างปุ่มไว้" + ล็อกเป้า (สลับเป้าด้วย LB/RB)
* สกิล 56 ตัว แยกเป็น damage / aoe / line / chain / heal / buff / debuff / dash / ground / summon / revive / passive
* สถานะผิดปกติ: พิษ ไหม้ แช่แข็ง ตรึง สตัน + โล่ดูดซับ
* มอนสเตอร์มี **ตารางความแค้น (threat)** จริง — แท็งก์ยั่วยุแล้วดึงได้
* ลีช: ถ้ามอนสเตอร์ถูกลากออกไกลเกิน 16 ช่อง จะกลับจุดเกิดและฟื้นเลือดเต็ม
* ตาย = เสีย EXP 5% **ไม่เสียไอเทม** (เพราะเราไม่อยากให้ตลาดผู้เล่นพัง)
* **มอนสเตอร์ที่สูงกว่าเกิน 10 เลเวลจะไล่ล่าเอง** ไม่ว่านิยามของมันจะ `aggressive`
  หรือไม่ และ**ยิ่งห่างยิ่งเห็นไกล** — ระยะสังเกตขยายถึงสองเท่าที่ 30 เลเวล
  (วัดจริง: ต่าง 10 เลเวล = 209px เท่าปกติ, ต่าง 20 = 316px, ต่าง 30 = 420px)
  นี่คือรั้วของแถบเลเวล: เดินเข้าโซนน้ำแข็งตอนเลเวล 12 ไม่ควรเป็นการไปเที่ยวชมวิว
  และสิ่งที่ทำให้รู้สึกแบบนั้นคือ*ระยะ* — ของที่สูงกว่าเรา 30 เลเวลควรออกเดินมา
  ตั้งแต่เรายังอ่านชื่อมันไม่จบ
  ไคลเอนต์ติดป้าย `‼` สีแดงและวงเต้นใต้เท้าให้ตัวที่จะไล่ล่า เพราะกฎที่มองไม่เห็น
  แล้วฆ่าเราได้ ไม่ใช่กฎ มันคือการซุ่มโจมตี

## 5.0 หีบศพจม — ดันเจียนสำหรับปาร์ตี้

ก่อนหน้านี้เกมนี้เป็น MMO ที่ไม่มีเหตุผลให้เล่นกับคนอื่นเลย ปาร์ตี้มีอยู่และ
แชร์ EXP ได้ แต่ไม่มีเนื้อหาไหน*ต้องการ*ปาร์ตี้ และเนื้อหาก็หยุดที่เลเวล 60
ทั้งที่แคปอยู่ที่ 70 หีบศพจมแก้ทั้งสองเรื่องด้วยของชิ้นเดียว

**ประตูเปิดให้เฉพาะปาร์ตี้** (`world.partyGate`) และนับจากเพื่อนที่ยืนอยู่ใน
*โซนเดียวกัน* ไม่ใช่จากรายชื่อในปาร์ตี้ — รายชื่อห้าคนที่อยู่คนละเมืองไม่ใช่ปาร์ตี้

**แผนผังเขียนด้วยมือ ไม่ได้สุ่ม** (`kind: 'dungeon'` ใน `buildGrid`) โซนอื่นเป็น
สนาม noise ที่เจาะทางเดินผ่าน ซึ่งเหมาะกับทุ่งกว้างแต่ทำดันเจียนไม่ได้: noise
ไม่มีประตู และทางเดินที่มองไม่เห็นปลายคือสิ่งที่ทำให้ดันเจียนน่ากลัว ทางเดินกว้าง
สองไทล์เพื่อให้ปาร์ตี้เดินเรียงแถวและคนหน้าคือคนที่โดน และทุกห้องใหญ่มีเสา —
เป็นที่กำบัง และเป็นสิ่งที่ pathfinding ของมอนสเตอร์ต้องแก้จริงๆ

**มอนสเตอร์สี่ชนิดตอบนิสัยการเล่นคนเดียวคนละอย่าง**: ทหารยามลงโทษการยืนนิ่ง
คณะขับร้องลงโทษการปล่อยตัวร่ายเวท สมอหลุมศพลงโทษการสู้ทีละตัว และเงาระเบียง
ลงโทษการปล่อยให้อะไรก็ตามเข้าถึงแถวหลัง — ตัวเดียวสู้คนเดียวชนะได้ทุกตัว
แต่ดันเจียนไม่เคยส่งมาทีละตัว

มอนสเตอร์อื่นทุกตัวในเกมใช้ลูปเดียวกัน: เดินเข้าหา ฟาด สุ่มสกิลเป็นบางครั้ง
ซึ่งพอสำหรับผีเร่ร่อน แต่ใช้กับบอสไม่ได้ เพราะไม่มีอะไรใน *การสุ่ม* ให้เรียนรู้ได้
— สกิลที่สุ่มออกมาไม่ใช่กลไก มันคือสภาพอากาศ `server/game/boss.js` จึงเขียน
การต่อสู้เป็นสคริปต์ที่ทำอะไรตามลำดับ เตือนก่อนท่าที่เจ็บ และขอสิ่งที่ร่างเดียวให้ไม่ได้

| เฟส | กลไก | ต้องการอะไร |
|---|---|---|
| 100–66% | **คำพิพากษา** วงบนพื้นใต้เท้าใครสักคน เตือนก่อน 1.3 วินาที | อ่านพื้นแล้วขยับ (คนเดียวก็ทำได้ — นี่คือบทเรียน) |
| 66–30% | **สมอหลุมศพ** สองตัวคนละฝั่ง ดูดเลือดคืนให้บอส 1.2%/วินาทีต่อตัว | ต้องมีคนแยกไปทุบ คนเดียวตีบอสไปด้วยทุบสมอไปด้วยไม่ทัน |
| ต่ำกว่า 30% | **ห้องถล่ม** วงซ้อนสองชั้นจากกลางตัวบอส ตรงกลางตาย ขอบรอด | ทุกคนต้องกระจาย ร่างเดียวยืนได้ที่เดียว |

การเตือนส่งเป็นอีเวนต์ `warn` ที่ไคลเอนต์วาดเป็นวงที่ค่อยๆ เต็มเหมือนนาฬิกา
(เวลาที่เหลือเป็น*ปริมาณ* ไม่ใช่การเดา) แต่**ดาเมจคิดที่เซิร์ฟเวอร์ตอนหมดเวลา**
ไคลเอนต์ไม่เคยเป็นคนตัดสินว่าใครหลบทัน

### รางวัลถูกจำกัดด้วยปฏิทิน ไม่ใช่ด้วยเวลาว่าง

บอสจ่ายสมบัติให้ตัวละครหนึ่งตัว **สัปดาห์ละครั้ง** (รีเซ็ตวันจันทร์ 00:00 UTC
เท่ากันทั้งเซิร์ฟเวอร์ กิลด์จะได้นัดกันได้ว่า "ลงวันอังคาร" โดยไม่มีนาฬิกาของใคร
เลื่อนไปเอง) ตีซ้ำยังได้ EXP หนึ่งในสี่ — ไปช่วยเพื่อนเคลียร์ไม่ควรเป็นการเสียเวลาเปล่า
— แต่ของที่ป้อนท่อระบายตีบวกถูกล็อกไว้

**ตราผนึกหีบศพ** ที่ได้มาหลอมเป็น**น้ำมันศักดิ์สิทธิ์**ได้ (6 ตรา + 2,000 AU)
ซึ่งเป็นของกันของแตกตอนตีบวก — ไม่ได้สร้างสกุลเงินใหม่ แต่เปิดทางใหม่เข้าสู่
ท่อระบายที่ลึกที่สุดที่มีอยู่แล้ว และทางนั้นผ่านปาร์ตี้เท่านั้น

### มอนสเตอร์เดินอ้อมกำแพงเป็นแล้ว

`zone.moveTo` เดิมไถลตามแกน X/Y มอนที่เป้าหมายอยู่หลังมุมอับจึงดันกำแพงอยู่ตลอด
`shared/pathfind.js` เอา BFS ที่ไคลเอนต์ใช้เดินออโต้มาใช้ร่วมกันทั้งสองฝั่ง
แต่มอนจะ**ลองเส้นตรงก่อนเสมอ** — ในที่โล่งการค้นกริดทุกเฟรมเพื่อเดินตรงคือการเสียแรงเปล่า
— แล้วค่อยหาเส้นทางเมื่อมีอะไรขวาง โดยเก็บเส้นทางไว้เดินต่ออีกครึ่งวินาทีก่อนคิดใหม่
วัดผลบนกำแพงยาวที่มีช่องเดียว: เดินเส้นตรงค้างอยู่ห่างเป้าหมาย 334px, มี pathfinding เข้าถึงที่ 13px


## 5.1 การนำเสนอโลก

ชุดสไปรต์ LPC มีแต่ตัวละคร ไม่มีไทล์พื้น เราจึงวาดโลกทั้งหมดด้วยโค้ด:

* **ไม่วาดเป็นไทล์สี่เหลี่ยม**: แผนที่ทั้งผืนถูกเพนต์ลงแคนวาสครั้งเดียวตอนเข้าโซน
  (`client/js/terrain.js`) แต่ละวัสดุลงผ่านมาสก์ที่มุมโค้งตามเพื่อนบ้านแล้วเบลอหนึ่งครั้ง
  ขอบหญ้า-ดิน-ทราย-หิมะจึงกลืนกันแทนที่จะชนกันเป็นเหลี่ยม 32px
* ชายน้ำเป็นฮาโลฟุ้งรอบผืนน้ำทั้งก้อน (ไม่ใช่ตีเส้นรอบไทล์ ซึ่งจะเห็นเป็นตาราง)
  บวกน้ำลึกที่เข้มขึ้นตรงกลาง และประกายคลื่นที่ขยับจริงทุกเฟรม
* กำแพงมีสันบนสว่าง หน้าผาด้านล่าง และเงาทอดลงพื้น → อ่านเป็นหน้าผาไม่ใช่บล็อก
* ต้นไม้และก้อนหินไม่ใช่ไทล์อีกต่อไป แต่เป็นทรงกลมนุ่มที่เรียงตามแกน Y
  ผู้เล่นจึงเดินลอดหลังพุ่มได้ และมีเงาสัมผัสพื้นทุกต้น
* รายละเอียดใกล้ตา: ใบหญ้า กรวด รอยแตกหิน ประกายหิมะ วาดทับตอนพรีเรนเดอร์
* **ของประดับ 28 ชนิด** (ต้นไม้ กก ป้ายหลุมศพ คบไฟ แท่งน้ำแข็ง ลัง ฯลฯ)
  สร้างจาก seed เดียวกับแผนที่บนเครื่องผู้เล่นเอง — ไม่กินแบนด์วิดท์และไม่กระทบการชน
* อาคารในเมืองเป็นข้อมูลที่เขียนมือ (`structures`) วาดเป็นบ้านหลังคาโค้ง มีชายคายื่น
  ปล่องไฟ หน้าต่างโค้งที่มีไฟอุ่นข้างใน ประตูโค้ง ป้ายร้านห้อยบนโครงเหล็ก และเงาใต้ตัวบ้าน
* ไล่สีตามธีมแต่ละโซน + แสงแบบบวก (additive) จากคบไฟ กองไฟ คริสตัล และประตูวาร์ป
  ในถ้ำผู้เล่นมีแสงติดตัว ทำให้มืดแต่ยังมองเห็น
* ประตูวาร์ปเป็นวงรีเรืองแสงมีซุ้มโค้ง อนุภาคลอย และป้ายชื่อปลายทาง
* **ปีก** (`client/js/wings.js`) วาดด้วยโค้ดเช่นกัน ไม่มีไฟล์ภาพเพิ่มแม้แต่ไฟล์เดียว
  หกแบบใน 4 สไตล์การวาด — ขนนก (ปีกนางฟ้า/อีกา/รุ่งอรุณ), พังผืด (ค้างคาว),
  ผลึก (น้ำแข็ง) และเปลวไฟ — แต่ละแบบมีสามท่ากระพือ และวาดแยกสามมุม
  (เห็นจากข้างหลัง จากข้างหน้า จากด้านข้าง) ให้ตรงกับแถวของสไปรต์ LPC
  ปีกวาด*ก่อน*ตัวละคร จึงอยู่หลังลำตัวจริงๆ กระพือเร็วขึ้นตอนวิ่ง
  และแบบที่มี `glow` จะมีฮาโลเบลอหนึ่งชั้นใต้ปีก

## 5.1.1 เอฟเฟคและธาตุ

ธาตุทั้งแปด (`shared/constants.js`) เคยเป็นแค่ตัวเลขคำนวณดาเมจ ตอนนี้มี
**หน้าตาของตัวเอง**อยู่ที่ `shared/elements.js` ที่เดียว — สามโทน (`core` สว่างกลาง,
`main` สีที่คนเรียกชื่อธาตุนั้น, `deep` ด้านเงา) บวก `shape` ที่บอกว่าจะวาดยังไง
สกิลไฟ, มอนสเตอร์ไฟที่ตาย และดาบไฟ จึงเป็นสีส้มชุดเดียวกันเสมอ

**สกิล 56 ตัวเคยใช้รูปทรงร่วมกันแค่ 5 แบบ** — วงกลมเส้น 2px สำหรับทุกอย่างที่มีรัศมี
เส้นตรงสำหรับทุกอย่างที่มีทิศทาง และวงแหวนอีกสามวง `client/js/skillfx.js` แยก
"รูปทรงมาจากสิ่งที่สกิลทำ" ออกจาก "หน้าตามาจากธาตุของสกิล" โนวาไฟกับโนวาน้ำแข็ง
จึงเป็นการเคลื่อนไหวเดียวกันในสองพาเลตต์ที่ไม่เหมือนกันเลย ทุกเอฟเฟควาดสี่ชั้น:

1. **บลูม** — รูปทรงเดิมวาดซ้ำสองครั้งแบบกว้างและจางมากในโหมดบวก (ไม่ใช้
   ฟิลเตอร์ `blur` เพราะมันแพงกว่าทั้งเฟรมรวมกันเมื่อเอฟเฟคซ้อนกันหลายอัน)
2. **ตัวรูปทรง** — ชั้นที่ตาอ่านจริง
3. **แกนกลาง** — สำเนาที่เล็กและขาวกว่า ทำให้ตรงกลางดูร้อน
4. **เศษซาก** — ประกาย สะเก็ด หรือละอองที่กระเด็นออกมา

ธาตุแต่ละตัววาดหนามต่างกัน: ไฟเป็นลิ้นเปลวที่บิดไปข้างๆ น้ำแข็งเป็นสะเก็ดแบนข้างเดียว
พายุเป็นเส้นหักสามทบ เงาเป็นม้วนที่พับกลับ แสงเป็นหอกตรง — และเอฟเฟคที่แตะพื้น
จะทิ้ง**รอยไหม้**ที่จางช้ากว่าตัวเอฟเฟคมาก

สกิลที่เป็นการฟาดฟันจริงๆ ยังเป็น `element: 'neutral'` เหมือนเดิม เพราะธาตุคูณดาเมจ
การแปะธาตุให้มันจะเปลี่ยนสมดุลเงียบๆ จึงเพิ่มฟิลด์ `look` ที่**มีผลกับภาพอย่างเดียว**แทน

**จังหวะการโดน** ประกอบจากสี่อย่างที่ทำงานพร้อมกัน: ตัวที่โดนกระเด็นถอยตามทิศของ
หมัด (`impact()`), วงแหวนกระแทกในสีของธาตุที่ฟาดมา, เลขดาเมจที่**ถูกเหวี่ยง**ขึ้น
แล้วตกตามแรงโน้มถ่วง (สลับข้างซ้าย-ขวาทุกครั้ง เลขจึงกระจายแทนที่จะทับกัน)
และตอนคริติคอล **นาฬิกาแอนิเมชันหยุด 60ms** — ตำแหน่งยังวิ่งต่อ โลกจึงไม่เคย
หลุดจากเซิร์ฟเวอร์เพราะเรื่องนี้

**ความตาย**แยกสองระดับโดยตั้งใจ: มอนธรรมดาแตกเป็นชิ้นที่ตกตามแรงโน้มถ่วง
ส่วนบอสได้โนวาในธาตุของมันเอง คลื่นกระแทกวิ่งไปกับพื้น จอสว่างวาบ กล้องสั่น
และรอยไหม้ที่อยู่นานสี่วินาที — ถ้าทุกการฆ่าหน้าตาแบบนี้ ก็จะไม่มีอันไหนพิเศษเลย

**เลเวลอัพและเปลี่ยนอาชีพ**เป็นลำแสงเดียวกัน ต่างกันที่ขนาดและความยาว
ตอนเปลี่ยนอาชีพคนที่ยืนอยู่ใกล้ๆ เห็นด้วย (เซิร์ฟเวอร์ส่ง `ascend` เข้าโซน)

**สภาพอากาศ** (`client/js/weather.js`) วาดใน**พิกัดจอ** ไม่ใช่พิกัดโลก
ซูมออกแล้วฝนจึงไม่กลายเป็นฝนปรอย — หนองน้ำมีฝนเฉียงกับฟ้าแลบ (จังหวะฟ้าแลบ
คำนวณจากนาฬิกาจริงเหมือนกลางวัน-กลางคืน ทุกเครื่องจึงเห็นพร้อมกันโดยไม่ต้องส่งอะไร)
โซนน้ำแข็งมีหิมะที่ส่ายตามลมกระโชก ถ้ำมีแพหมอกเลื่อนผ่าน

**ออร่าอาวุธ**ตอบคำถามสี่ข้อที่ต่างกัน และซ้อนกันได้ทั้งสี่ เพราะมันคนละชั้นกันจริง:

1. **ระดับตีบวก** — *ลงทุนไปเท่าไหร่* (ความสว่าง แสงบนพื้น ความถี่ประกาย)
   15 ขั้น ขั้นละเลเวล ไม่ใช่ 7 ขั้นแบบเดิมที่ทำให้แปดเลเวลที่คนจ่ายเงินไป
   หน้าตาเหมือนเลเวลล่างเป๊ะ แบ่งสามช่วง: ไฟ +1..+7 · สนธยา +8..+11
   (เริ่มที่เลเวลที่พลาดแล้วของพัง) · นิรันดร์ +12..+15
2. **ธาตุ** — *มันคืออะไร* (สีและพฤติกรรม) ไฟลอยขึ้นและเร่งตัว น้ำแข็งไหลลง
   และค้างอยู่ พายุสะบัดแล้วดับทันที เงาไหลย้อยลงจากคมดาบ
3. **เครื่องหมายพิเศษ** — *มันทำอะไรกับคนที่โดน* แปดแบบ (คริติคอล พิษ เลือดไหล
   ดูดเลือด เผามานา คำสาป เยียวยา โล่) สองแบบแรกอ่านจากตัวเลขในไอเทมเอง
   จึงโกหกไม่ได้ ที่เหลือไอเทมประกาศ
4. **ลายเซ็นตำนาน** — หกลาย เลือกจากธาตุของชิ้นนั้น ของตำนานที่เพิ่มทีหลัง
   จึงได้ลายที่ถูกต้องเองโดยอัตโนมัติ

ดาบไฟ +0 ก็ยังลุก ดาบเปล่า +12 ก็ยังเจิดจ้า และดาบไฟ +12 ที่ดูดเลือด
ใส่ทั้งสามชั้นพร้อมกัน — ซึ่งเป็นเหตุผลทั้งหมดที่มันเป็นสี่ตาราง ไม่ใช่ตารางเดียว
ที่ลิสต์ทุกส่วนผสม

## 5.2 อินเทอร์เฟซ

UI ทั้งหมดเป็น DOM/CSS วางทับแคนวาส และหน้าตาถูกควบคุมด้วย**ชั้นโทเคนชุดเดียว**
(`client/css/style.css`) ธีมทั้งสามนิยามทับเฉพาะตัวแปร ไม่มีคอมโพเนนต์ไหนแตกสาขาตามธีม

| ธีม | บุคลิก |
|---|---|
| `pixel` (ค่าเริ่มต้น) | มุมบาก ขอบคม เงาแข็ง สีชุดเดียวกับสไปรต์ |
| `ornate` | หนังกับทอง กรอบสองชั้น เพชรมุม หัวเรื่องฟอนต์เซริฟ |
| `glass` | กระจกฝ้า เส้นขอบบาง ระยะห่างเยอะ บังฉากน้อยที่สุด |

สลับได้ในเกมที่เมนูตั้งค่า (F1) และจำค่าไว้ใน `localStorage`

**เลย์เอาต์แบบ MMO มือถือ**: ตัวตน (พอร์ตเทรต + เลเวล + HP/SP + CP) มุมซ้ายบน,
กระเป๋าเงินถัดมา, แผนที่ย่อ + ชื่อโซน + พิกัดมุมขวาบน, ตัวติดตามภารกิจชิดซ้าย,
แถบเมนูแนวตั้งชิดขวา, แถบสกิล + ปุ่ม AUTO + ช่องไอเทมด่วนด้านล่าง
และแถบ EXP/Job พาดขอบล่างสุด · แชทมีแท็บแยกช่อง
บนมือถือ แถบสกิลจะยกให้แป้นทัชแทน แล้วเหลือเฉพาะ AUTO/เป้าหมาย/ไอเทมด่วน

**สู้อัตโนมัติ (AUTO)** ทำงานฝั่งไคลเอนต์ล้วน: เลือกเป้าใกล้สุด เดินเข้าไป ตี
ใช้สกิลที่พร้อม และเก็บของที่ตก — ผู้เล่นแตะปุ่มเดินเมื่อไรก็แย่งการควบคุมคืนทันที
เซิร์ฟเวอร์ไม่รู้จัก AUTO เลย จึงไม่มีทางใช้มันโกงเกิน

**หน้าต่างทุกบานใช้คอมโพเนนต์ชุดเดียวกัน**: ตารางช่องไอเทม + การ์ดรายละเอียด
ทั้งกระเป๋า ร้านค้า ขายของ ตีบวก ซ่อม คราฟต์ คลังเก็บของ และตลาดผู้เล่น
หน้าตัวละครมี**ช่องสวมใส่ 9 ช่องล้อมรอบตัวละครจริง** คลิกช่องเพื่อถอด และมีค่า CP กำกับ

**ไอคอนวาดด้วยโค้ด** (`client/js/icons.js`): 30 กว่ารูปทรงบนกริด 32x32
แล้วแมปเข้ากับไอเทมทุกชิ้นตามประเภท/ช่องสวมใส่ และสกิลทุกตัวตามชนิด/ธาตุ
ไอเทมใหม่จึงมีไอคอนทันทีโดยไม่ต้องวาดเพิ่ม ขอบช่องบอกความหายาก มีป้าย +N และจำนวนซ้อน

## 6. ความก้าวหน้า

* Base Lv. สูงสุด 99, Job Lv. สูงสุด 50
* เส้น EXP ชันกว่าเกมสมัยใหม่โดยตั้งใจ (`28·Lv^2.05 + 40·Lv + 60`)
* ล่ามอนสเตอร์ที่เลเวลห่างเกิน 12 ได้ EXP 60%, ห่างเกิน 20 ได้ 25% — กันพาวเวอร์เลเวล
* ปาร์ตี้: EXP รวม +10% ต่อสมาชิกหนึ่งคน แล้วหารเท่ากัน **เฉพาะคนที่อยู่ในระยะ**

## 7. สังคม

* ปาร์ตี้สูงสุด 6 คน มีแถบเลือดสมาชิกและระบบเชิญ/ตอบรับ
* แชท 4 ช่อง: รอบตัว / ปาร์ตี้ / ซื้อขาย / โลก
* ตลาดผู้เล่นแบบฝากขาย 24 ชม. (ขายได้แม้เจ้าของออฟไลน์ — เงินเข้าบัญชีทันที)

## 7.1 กิลด์

ปาร์ตี้อยู่ได้เย็นเดียว ล่าบอสเสร็จ ล็อกรางวัลรายสัปดาห์เด้ง แล้วก็แยกย้าย
ไม่มีอะไรทำให้คนกลุ่มเดิมกลับมาเจอกันวันพฤหัสหน้า กิลด์คือสิ่งนั้น และ**เก็บลง
ฐานข้อมูลจริง** ไม่เหมือนปาร์ตี้เดิมที่อยู่ใน `Map` แล้วหายตอน deploy

สามเรื่องที่ตั้งใจออกแบบไว้แบบนี้:

**ยศคุมคลัง ไม่ได้คุมแชท** ใครก็พูดได้ แต่คนที่เบิกของได้ต้องมียศพอ คลังกิลด์
ที่ใครก็หยิบได้คือถุงที่คนแปลกหน้าคนแรกกวาดเกลี้ยง และเหตุการณ์แบบนั้นครั้งเดียว
ก็ฆ่ากิลด์ได้ เพดานเบิกคิดเป็น*รายสัปดาห์ต่อคน*:

| ยศ | เบิกได้/สัปดาห์ | ชวนคน | เตะ | จัดการ |
|---|---|---|---|---|
| ผู้มาใหม่ | — | — | — | — |
| สมาชิก | 3 ชิ้น | — | — | — |
| รุ่นพี่ | 10 ชิ้น | ✓ | — | — |
| ผู้ช่วยหัวหน้า | 30 ชิ้น | ✓ | ✓ | — |
| หัวหน้ากิลด์ | ไม่จำกัด | ✓ | ✓ | ✓ |

**คลังย้ายของ ไม่ได้เสกของ** ไม่มีอะไรถูกสร้างขึ้นตอนฝากหรือเบิก มันจึงทำให้
เงินเฟ้อไม่ได้เลย เป็นแค่ความสะดวกกับการทดสอบความไว้ใจ ไม่ใช่ท่อน้ำเข้า

**ค่าก่อตั้ง 250,000 ออรัม และค่าบำรุงสัปดาห์ละ 40,000** นี่คือประเด็น: กิลด์คือ
ท่อระบายที่ไหลตลอดเวลาจากผู้เล่นที่รวยที่สุดในเซิร์ฟเวอร์ ซึ่งเป็นตำแหน่งที่
เศรษฐกิจแบบเงินหายากต้องการท่อระบายพอดี กิลด์ที่จ่ายไม่ไหว**ไม่ถูกยุบ** —
การลงโทษแบบนั้นหนักเกินไปสำหรับสัปดาห์ที่เงียบ — แค่ล็อกคลังไว้จนกว่าจะมีคนจ่าย

ปาร์ตี้ก็ย้ายลงฐานข้อมูลด้วย และ**การออกจากเกมไม่ใช่การออกจากปาร์ตี้อีกต่อไป**
ปาร์ตี้จะถูกเก็บกวาดเมื่อไม่มีใครแตะมันเลย 12 ชั่วโมง ซึ่งตรงกับที่คนคาดหวัง
มากกว่าการหายทันทีที่เน็ตหลุด

## 7.2 แดชบอร์ดเศรษฐกิจ

ทั้งโครงเรื่องของเกมนี้ตั้งอยู่บนคำกล่าวอ้างว่า "เงินหายาก และท่อระบายชนะท่อน้ำเข้า"
— แต่ `world.stats` นับ minted/burned มาตั้งแต่วันแรกโดยไม่เคยมีใครอ่านกลับเลย
`/admin` เปิดให้ดูได้แล้ว **ปิดไว้เป็นค่าเริ่มต้น** จะเปิดต้องตั้ง `EMBERFALL_ADMIN_TOKEN`

ที่สำคัญกว่าตัวเลขรวมคือ**การแยกว่าท่อระบายไหนทำงานจริง** — ตัวเลข burned
ตัวเดียวบอกได้แค่ว่าเงินกำลังออก ไม่ได้บอกว่าท่อที่เรา*ออกแบบ*คือท่อที่ทำงาน
ถ้าตีบวกกินไป 90% และค่าเดินทางกินไป 0.1% แปลว่าค่าเดินทางเป็นแค่ของประดับ
ทุกจุดที่เผาหรือสร้างเงินจึงติดป้ายที่มาไว้หมด (shop, refine, craft, market-tax,
travel, guild-found, guild-upkeep, monster-drop, quest, npc-sell)

หน้านี้ยังกระทบยอด **"เงินที่ควรมี" กับ "เงินที่มีอยู่จริง"** ได้ด้วย: เดินนับ
กระเป๋าทุกใบ คลังทุกคลัง และคลังกิลด์ทุกกิลด์ แล้วเทียบกับ minted − burned
ถ้าสองตัวนี้แยกจากกันเมื่อไหร่ แปลว่ามีอะไรสร้างเงินโดยไม่มีใครจดไว้

## 8. สิ่งที่เสริมเข้ามาเองนอกเหนือจากที่ขอ

1. **ระบบธาตุ 8 ธาตุ** ที่ทำให้ของแต่ละสายมีตลาดของตัวเอง
2. **ความคงทนอุปกรณ์** เป็นบ่อดูดเงินที่สม่ำเสมอกว่าการเก็บภาษี
3. **ตัวหน่วงราคาขาย NPC รายวัน** กันการฟาร์มของซ้ำๆ ขายกินส่วนต่าง
4. **คราฟต์** ที่กินวัตถุดิบจากมอนสเตอร์ ทำให้ของดรอปมีมูลค่าจริง
5. **การขโมยของ (Pilfer)** และ **การชุบชีวิต** ที่กินไอเทมหายาก
6. **มินิแมป ล็อกเป้า และตัวเลขดาเมจลอย** เพื่อให้เล่นด้วยจอยได้จริง
7. **ระบบทำนายการเดินฝั่งไคลเอนต์** ทำให้เล่นลื่นแม้ปิงสูง
