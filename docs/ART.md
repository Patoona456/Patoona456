# ใส่ asset ใหม่เข้าเกม

## สรุปสั้นที่สุด

1. `npm run sheet -- ไฟล์.png` → มันจะบอกว่ากริดเท่าไร และต้องประกาศอะไร
2. ถ้าขึ้นว่า **"ตรงกับ LPC พอดี"** → วางไฟล์ลงโฟลเดอร์ แล้วชี้จากข้อมูลไอเทม/มอน จบ
3. ถ้าไม่ตรง → ก๊อปบล็อก `defineLayout(...)` ที่มันพิมพ์ให้ ไปใส่ `shared/sheets.js`
   แล้วบอกชีตนั้นว่าใช้ layout ไหน

**ไม่ต้องแก้ renderer** ไม่ว่าขนาดเฟรมหรือจำนวนแถวจะเป็นเท่าไร

## รูปแบบที่ระบบรับ

### แบบมาตรฐาน (LPC)
PNG **832×1344** = 13 คอลัมน์ × 21 แถว ของเฟรม **64×64**

| แถว | ท่า | เฟรม |
|---|---|---|
| 0-3 | ร่ายเวท | 7 |
| 4-7 | แทง | 8 |
| 8-11 | เดิน (แถวแรกของแต่ละทิศ = ยืนเฉยๆ) | 9 |
| 12-15 | ฟัน | 6 |
| 16-19 | ยิงธนู | 13 |
| 20 | เจ็บ (ทิศเดียว) | 6 |

4 แถวต่อท่า = 4 ทิศ เรียง **บน · ซ้าย · ล่าง · ขวา**

### แบบอื่น
ประกาศใน `shared/sheets.js`:

```js
defineLayout('ชื่อ', {
  frame: { w: 96, h: 128 },   // ขนาดเฟรมจริง
  cols: 6, rows: 8,
  dirRows: 4,                 // 4 = มี 4 ทิศ, 1 = ทิศเดียว
  anchor: 0.82,               // เท้าอยู่ที่กี่ % ของความสูงเฟรม (ไว้จัดให้ยืนติดพื้น)
  anims: {
    walk: { row: 0, frames: 6, fps: 10 },
    slash: { row: 4, frames: 4, fps: 14 },
    // ท่าที่ไม่ได้ใส่ จะตกไปใช้ค่าของ LPC แทน ไม่พัง
  },
});
```

ท่าที่ขาดไปจะ fallback ไม่ทำให้จอพัง และถ้าขนาดไฟล์ไม่ตรงกับที่ประกาศ
คอนโซลจะเตือนครั้งเดียวต่อไฟล์ พร้อมบอกว่าคาดหวังเท่าไร

## ไฟล์ไปไว้ตรงไหน

```
assets/lpc/<ชั้น>/<male|female>/<ชื่อ>.png    ตัวละคร เกราะ อาวุธ
assets/lpc/weapon/either/<ชื่อ>.png           อาวุธที่ใช้ไฟล์เดียวทั้งสองเพศ
assets/lpc/mob/<ชื่อ>.png                     มอนสเตอร์ (ไม่แยกเพศ)
```

ชั้นที่มี: `body eyes hair head torso legs feet hands belt offhand weapon`

**ชี้จากข้อมูล** — ไอเทมใน `shared/data/items.js`:
```js
sprite: { layer: 'torso', key: 'ชื่อไฟล์', gendered: true }
sprite: { layer: 'weapon', key: 'ชื่อไฟล์', gendered: true, tint: '#f2d79a' }
```
`tint` ย้อมสีทั้งชีตครั้งเดียวแล้วแคชไว้ — ใช้ทำของระดับสูงให้ดูต่างโดยไม่ต้องวาดใหม่

### อาวุธแปดคลาสใหม่ยังยืมศิลป์เก่าอยู่

ชนิดอาวุธขยายจาก 4 เป็น 12 ตามชีต แต่ศิลป์ของแปดคลาสใหม่ยังไม่มา ของใหม่
ทุกชิ้นจึงชี้ไปที่ไฟล์ที่มีอยู่แล้ว **พร้อม `tint` ที่บอกว่ามันควรเป็นสีอะไร**
เพื่อไม่ให้ใครถืออาวุธล่องหน ตารางนี้คือรายการที่ต้องแก้เมื่อชีตจริงมาถึง —
แก้ `key` อย่างเดียว ชิ้นละบรรทัด

| คลาส | ยืม `key` | ชื่อไฟล์ที่ควรจะเป็น |
|---|---|---|
| sword | `dagger` | `weapon/<เพศ>/sword.png` |
| greatsword | `longspear` (either) | `weapon/either/greatsword.png` |
| dagger | `dagger` | ตรงอยู่แล้ว |
| axe | `dagger` | `weapon/<เพศ>/axe.png` |
| knuckle | `dagger` | `weapon/<เพศ>/knuckle.png` |
| throwing | `dagger` | `weapon/<เพศ>/throwing.png` |
| staff | `wand` / `steelwand` | `weapon/<เพศ>/staff.png` |
| wand | `wand` / `steelwand` | ตรงอยู่แล้ว |
| special | `longspear` / `steelwand` | `weapon/<เพศ>/special.png` |

โล่ (`shield`) ใช้ชั้น `offhand` อยู่แล้ว ไม่ต้องยืม

มอนใน `shared/data/monsters.js`:
```js
sprite: { kind: 'sheet', key: 'ชื่อไฟล์', tint: '#c8b9d8', scale: 1.15 }
sprite: { kind: 'blob', shape: 'spiky', color: '#8a6a4a' }   // วาดด้วยโค้ด ไม่ต้องมีไฟล์
```

## เอฟเฟคตีบวก (+1 +3 +5 +7)

ระดับอยู่ใน `shared/refineglow.js` — สี่ระดับแรกเป็นไฟ:

| ระดับ | ชื่อ |
|---|---|
| +1 | ประกายไฟ |
| +3 | เปลวอ่อน |
| +5 | เพลิงกล้า |
| +7 | เพลิงขาว |

ตอนนี้ทุกระดับ **วาดด้วยโค้ด** (เอาชั้นอาวุธมาย้อมสีแล้วซ้อนแบบ additive)
ถ้าจะใส่ภาพจริง ใส่ `sheet` ลงในระดับนั้น:

```js
{ at: 5, name: 'เพลิงกล้า', ..., sheet: '/assets/fx/fire5.png', loopMs: 800 },
```

ชีตเอฟเฟคต้องวาดบนกริดเดียวกับตัวละคร (หรือประกาศ layout ของตัวเอง)
เพราะมันเล่นทับตัวละครทีละเฟรมตามท่าที่กำลังทำ — เปลวไฟจะขยับตามจังหวะฟันจริงๆ
`loopMs` คือให้ไฟวนด้วยนาฬิกาตัวเอง จะได้ลุกต่อเนื่องแม้ตัวละครยืนเฉย

**ใส่ทีละระดับได้** ระดับที่ยังไม่มีภาพจะใช้ออร่าโค้ดเหมือนเดิม
ระดับที่มีภาพแล้ว ออร่าจะเบาลงเหลือ 35% เพื่อไม่ให้ทับกันจนเละ
