Greenmire Bestiary

มอนสเตอร์ทั้ง 8 ตัวของทุ่งกรีนไมร์ พร้อมตัวช่วยของบอส: สเตตัส ท่าต่อสู้และวิธีรับมือ ของดรอปและโอกาส จุดเกิดบนแผนที่ และไฟล์ asset ทุกไฟล์ที่ใช้ ตัวเลขทั้งหมดดึงจากโค้ดเกมโดยตรง

กลไกที่มอนใช้

ท่าพิเศษทุกท่าตั้งค่าในข้อมูลมอน (shared/data/monsters.js) และเซิร์ฟเวอร์เป็นคนตัดสินว่าใครโดน ท่าที่เจ็บจะมีวงหรือเลนเตือนบนพื้นก่อนเสมอ ผู้เล่นจึงเรียนรู้และหลบได้

burst

วงเตือนบนพื้น นับถอยหลัง tell แล้วระเบิด ใครยังอยู่ในวงโดน ตั้งให้ขึ้นรอบตัวมอนหรือใต้เท้าเป้าหมาย (at: 'target') ก็ได้ ตรึงคนที่โดน (root) และตีหลายครั้ง (pulses) ได้ บอสมีหลายท่า แต่ละท่ามี cooldown ของตัวเองและไม่ออกซ้อนกัน

charge

เลนเตือนจากตัวมอนผ่านจุดที่เป้ายืน แล้วมอนพุ่งตามเลน ชนทุกคนในเลนครั้งเดียว เลนล็อกตั้งแต่ตอนเตือน การก้าวออกด้านข้างจึงหลบได้

shot / kite

ยิงกระสุนที่บินตามเป้า ดาเมจลงตอนกระสุนถึง ส่วน kite คือถ้าเป้าเข้ามาใกล้กว่าระยะที่ตั้ง มอนจะถอยหนีระหว่างรอยิงนัดถัดไป

leap

วงเตือนใต้เท้าเป้า มอนย่อตัว กระโดดโค้งข้ามไปลงตรงวง จุดลงล็อกไว้แล้ว วิ่งออกจากวงก็รอด

howl

วงรอบตัวมอน คนที่ยังอยู่ในวงช้าลง และมอนตีแรงขึ้นชั่วคราว

enrage

เมื่อเลือดต่ำกว่าที่ตั้ง มอนคลั่งครั้งเดียว ตีแรงขึ้น เร็วขึ้น ตีถี่ขึ้น มีออร่าแดงและแบนเนอร์ Phase 2 ถ้ามอนหนีกลับที่หรือเกิดใหม่ จะกลับเป็นปกติ

calls

บอสเรียกตัวช่วยมาฟื้นเลือดตัวเองทุกวินาทีจนกว่าจะถูกตัด เรียกใหม่ได้เมื่อตัวช่วยชุดเดิมหมดแล้ว

sprite.fly / lunge / hop

ตัวบินลอยเหนือเงาและโยกขึ้นลง ตัวที่พุ่งแทงจะพุ่งเข้าแล้วถอยกลับ ตัวที่กระโดดจะลอยเป็นโค้งตามความสูงที่ตั้ง

กติกาของดรอป

  • ของตกลงพื้นพร้อมท่าตกของแต่ละชิ้น นอนบนพื้นเป็นกองตามจำนวน (4 ระดับ) และมีเอฟเฟคตอนเก็บ
  • คนที่ตีมอนตัวนั้นจะได้สิทธิ์เก็บก่อน 25 วินาที หลังจากนั้นใครก็เก็บได้ และของหายไปเองใน 120 วินาที
  • บอสและมินิบอส: ต้องทำดาเมจอย่างน้อย 10% ของเลือดบอส (นับรวมทั้งปาร์ตี้) ถึงจะได้ของ คนที่มาตีแค่ทีเดียวได้ EXP แต่ไม่ได้ของ
  • บอสทุกตัวดรอปของบังคับชุดเดียวกัน: ยาชุบชีวิต ม้วนเจาะเกราะ ตั๋วกาชา หินนำโชคตีบวก
  • กล่องทุกชนิดซื้อขายได้ มอนยิ่งยากเรทกล่องยิ่งดี ส่วนมอนง่ายที่บอทชอบฟาร์มได้เรทต่ำสุด

เพิ่มมอนตัวใหม่

  1. วางชีตท่าทางไว้ที่ assets/mob/source/ เป็นภาพพื้นโปร่งใส แถวละหนึ่งท่า
  2. เพิ่มรายการใน MOBS ของ tools/slice-mob.py: ระบุขอบบนล่างของแต่ละแถว จำนวนเฟรม ช่วงคอลัมน์หรือจุดตัดเมื่อเฟรมติดกัน ป้ายชื่อที่ต้องลบ (blank) และแถบเอฟเฟค (fx)
  3. รัน python3 tools/slice-mob.py <key> preview.png จะได้ atlas assets/mob/<key>.webp แถบเอฟเฟค <key>_fx.webp และข้อมูลใน shared/data/mobart.js
  4. วางชีตของดรอปไว้ที่ assets/ui/source/ แล้วเพิ่มใน SHEETS ของ tools/slice-drops.py ของดรอปทุกตัวรวมอยู่ในไฟล์เดียว assets/ui/drops.webp เดโมจึงไม่เพิ่มไฟล์
  5. เพิ่มไอเทมใน shared/data/items.js (ภาพ DROP('ชื่อ_1') และชนิดกอง loot) และมอนใน shared/data/monsters.js (sprite: { kind: 'frames', key } พร้อมท่าพิเศษ)
  6. ใส่จุดเกิดใน shared/data/maps.js แล้วรัน npm test เทสต์จะตรวจว่าจุดเกิดเดินถึงได้ ของดรอปมีจริง บอสดรอปของบังคับครบ และค่าความแม่นยำยังสมดุล

ไฟล์อยู่ตรงไหน

assets/
  mob/
    source/            ชีตต้นฉบับที่วาดมา (ไม่ถูกส่งไปกับเดโม)
    <key>.webp         atlas ท่าทาง: หนึ่งแถวต่อหนึ่งท่า ทุกเฟรมยืนบนเส้นเท้าเดียวกัน
    <key>_fx.webp      แถบเอฟเฟคจากชีต (ลูกเวท รากไม้ รอยข่วน ระเบิด)
  ui/
    source/*_drops.png ชีตของดรอปต้นฉบับ
    drops.webp         ของดรอปทุกตัวในไฟล์เดียว: ไอคอน ท่าตก กองบนพื้น เอฟเฟคตอนเก็บ
  maps/greenmire.webp  ภาพแผนที่ทุ่งกรีนไมร์
shared/data/
  monsters.js          สเตตัส ท่าพิเศษ ดรอป
  mobart.js            ขนาดช่องเฟรมและจำนวนเฟรมต่อท่า (สร้างอัตโนมัติ)
  dropart.js           ตำแหน่งภาพดรอปใน drops.webp (สร้างอัตโนมัติ)
  items.js             ไอเทม ชื่อ ราคา คำอธิบาย
  maps.js              จุดเกิดและทางวาร์ป
tools/
  slice-mob.py         ตัดชีตมอน
  slice-drops.py       ตัดชีตดรอป
